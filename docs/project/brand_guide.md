# 🎨 Brand Guide

> Version: 1.0
>
> Status: Draft

---

# 📖 Purpose

This document defines the visual identity of the **GnuCash Persian** project.

The goal is to keep all project assets visually consistent while allowing future redesign without changing the documentation.

The current branding is temporary and may evolve over time.

---

# 🎯 Brand Principles

The project identity should be:

- Simple
- Professional
- Community-driven
- Open Source
- Clean
- Accessible
- Consistent

---

# 🖼 Logo

Temporary logo location:

```text
assets/logo/logo.svg
```

Dark mode version:

```text
assets/logo/logo-dark.svg
```

Light mode version:

```text
assets/logo/logo-light.svg
```

Favicon:

```text
assets/logo/favicon.svg
```

The logo should be simple enough to work at 24×24 pixels.

---

# 📸 Screenshots

Store screenshots here:

```text
assets/screenshots/
```

Naming convention:

```text
dashboard.png

reports-balance-sheet.png

create-account-dialog.png
```

Avoid names such as:

```text
image1.png

new.png

test.png
```

---

# 🧩 Icons

Store icons under:

```text
assets/icons/
```

Prefer:

- SVG
- Simple outlines
- Consistent style

---

# 🗂 Brand Assets

Recommended structure:

```text
assets/

logo/
banner/
icons/
screenshots/
brand/
```

---

# 📝 Writing Style

Visual assets should support the documentation.

Avoid decorative graphics that do not improve understanding.

---

# 🌗 Light & Dark Mode

When possible:

- Support both light and dark backgrounds.
- Use transparent SVG files.
- Ensure sufficient contrast.

---

# 📏 Image Guidelines

Prefer:

- SVG
- PNG

Avoid:

- Blurry screenshots
- Oversized files
- Watermarks

---

# ♿ Accessibility

Visual elements should:

- Maintain sufficient contrast
- Include descriptive alt text
- Avoid relying only on color to convey meaning
