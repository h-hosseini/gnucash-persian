# 📖 Overview

This document defines the overall architecture of the **GnuCash Persian** project.

Its purpose is to establish a clear structure for the repository, documentation, community, and future development.

This document is considered the architectural reference for the entire project.

---

# 🎯 Vision

Our goal is to build the largest community-driven Persian knowledge base for GnuCash.

The project is more than a translation.

It aims to become an ecosystem including:

- Documentation
- Localization
- Accounting Knowledge
- Iranian Taxation
- Templates
- Plugins
- Scripts
- Tools
- Examples
- Community Resources

---

# 🏛 Project Principles

The project follows these principles:

- Open Source
- Community Driven
- Documentation First
- Beginner Friendly
- Professional
- Maintainable
- Scalable
