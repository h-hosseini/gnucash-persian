## معرفی

**کتاب راهنمای فارسی GnuCash** یک پروژه متن‌باز و جامعه‌محور است که با هدف تبدیل GnuCash به یک راهکار حرفه‌ای حسابداری برای کاربران و سازمان‌های فارسی‌زبان ایجاد شده است.

این پروژه شامل مستندات، راهنماهای حسابداری، بومی‌سازی، منابع مالیاتی، قالب‌ها، افزونه‌ها، ابزارهای توسعه، یکپارچه‌سازی با سایر سامانه‌ها و مثال‌های واقعی است.

> **این پروژه مستقل بوده و هیچ وابستگی رسمی به پروژه GnuCash ندارد.**

ایجاد جامع‌ترین مرجع متن‌باز فارسی برای GnuCash از طریق ترکیب دانش حسابداری، توسعه نرم‌افزار، بومی‌سازی و مشارکت جامعه.
